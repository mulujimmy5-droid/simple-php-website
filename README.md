# Simple PHP Website
A simple web application built to demonstrate how a wemsite can collect information from users and store that information in a MySQL database.

## Technologies 
-HTML
-CSS
-JavaScript
-PHP
-MySQL
-Apache
-Git
-GitHub

## Project Architecture
The application  will follow this general flow:

user → HTML/CSS/JavaScript → PHP → MySQL → stored data

## Development Environment
The project is being developed locally using:
-Visual Studio Code
-XAMPP Apache
-PHP
-MySQL 8.0
-MySQL Workbench
-Git
-GitHub

## Project Goals
The project will demonstrate:
1. Creating a web form.
2. Validating users input with JavaScript.
3. Processing form data with PHP.
4. Connecting PHP to MySQL.
5. Storing user data in MySQL.
6. Retrieving and displaying stored data.
7. Applying basic web security practices.
8. Using Git and GitHub for version control.

Currently in the project setup and documentation stage.
